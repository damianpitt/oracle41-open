# Security Policy

## Supported Versions

Security fixes are provided for the latest minor release line.

## Reporting a Vulnerability

Do not open a public issue for sensitive vulnerabilities.

Use GitHub Security Advisories (private report) for this repository.

If private advisories are not available yet, contact maintainers directly and include:

- Impact summary
- Reproduction steps
- Affected versions
- Suggested mitigation (if known)

## Disclosure

After a fix is available, a coordinated public disclosure will be published with:

- Affected versions
- Fixed versions
- Upgrade guidance
