# Code of Conduct

## Our Standard

Oracle41 Open is intended to be a respectful, constructive, and technically focused open-source project. Contributors are expected to communicate professionally, assume good faith, and keep discussions focused on improving the software.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, deliberate disruption, and publishing private information without consent.

## Enforcement

Report conduct concerns privately to the repository maintainers using the security contact listed in `SECURITY.md`. Reports will be reviewed and handled proportionally to the behavior and project context.

Maintainers may remove comments, close discussions, or restrict participation when necessary to protect the project community.
