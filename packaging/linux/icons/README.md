# Oracle41 Open Linux Icon

Monochrome cheetah-eye application icon for Oracle41 Open. The scalable SVG is
the source artwork; PNG exports are supplied for standard Linux desktop sizes.

## Install

Copy the `hicolor` directory into `/usr/share/icons/` (system-wide) or
`~/.local/share/icons/` (per-user). The icon name is
`io.github.damianpitt.oracle41_open`.

For example, an application desktop file can use:

```ini
Icon=io.github.damianpitt.oracle41_open
```
